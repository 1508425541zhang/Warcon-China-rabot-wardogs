# 赛后自动荣誉公告

入口：自动化 → **赛后自动发布 · 荣誉公告** → 设置赛后公告与模板。

该入口编辑现有“对局广播”规则，不重复创建第二条广播规则。勾选“自动生成本局获奖名单并广播”，修改模板后保存；规则本身也须启用。默认不新增广播，现有对局结束／开始消息继续沿用。

## 六个奖项

| 奖项 | 选择标准 |
| --- | --- |
| 本局MVP | 击杀 / max(死亡,1) 最大，有击杀才参与 |
| 最佳单次多杀 | 同一玩家、同一游戏时间戳的有效击杀最多，至少2杀；接口没有攻击动作ID，所以这是多杀近似值 |
| 最佳一命连杀 | 两次死亡之间的有效击杀最多；队杀、自杀不算有效击杀，任何死亡均终止连杀 |
| 本场赚钱最多 | 对局期间观测到的金钱净增最多；已消费金额无法恢复，因此不是总收入 |
| 本场最富玩家 | 赛末最后观测到的持有金钱最多，与净增分开 |
| 在线最久 | 本局累计已观测在线秒数最多 |

每项只选第一名。并列者使用本局随机种子抽取一人；种子、旧局玩家数据和击杀统计保存至对局快照，同一局重试不重抽。玩家可能获得多个奖项。无可靠数据或数值均为0的奖项跳过。

工程／医疗贡献分尚无已接入数据源，不自动编造该奖项。榜单依据本面板实际观测，停机、漏失日志、重连等可能影响完整性；击杀日志在快照之后迟到的事件不会追溯改写已广播结果。

## 模板导入与编辑

- 文字文件 `.txt`：导入“比赛结束时”消息，最多200字符。
- JSON文件：导入六个奖项模板和奖项启用开关，最多16KB。点击“下载当前JSON模板”即可取得格式正确的样例。
- 每个奖项模板最多200字符，留空表示跳过该项。
- 可用奖项字段：`{name}`、`{value}`、`{kills}`、`{deaths}`、`{previous}`。
- 导入只填充编辑框，必须保存规则才生效。不能通过模板上传修改玩家数据或执行命令。
- 使用自动生成模板按钮恢复六个默认奖项格式。

公告进入现有广播发送队列，发送状态可在自动化近期操作及审计中查看。换图导致人数临时归零时沿用对局广播的最多3分钟等待；等待期间进程重启可能丢失尚未入队的通知，但不会为过去所有对局补发公告。已入队内容和获奖快照不重抽。
