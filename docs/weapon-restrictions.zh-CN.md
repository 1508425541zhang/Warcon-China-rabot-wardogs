# 自动化：换边与武器限制

入口：服务器 → 自动化。展开“禁止自行换边”或“武器／载具限制”直接设置。

## 禁止自行换边

沿用已有规则和执行记录，只移动设置入口，不重置已启用配置。旧独立地址继续可访问。

## 武器／载具限制

1. 确认游戏已向 Warcon 回传 Kill Feed。
2. 搜索勾选具体来源，或选整类来源。整类包含该前缀以后新出现的武器。
3. 载具本体和车载武器可能使用不同 ID；可分别勾选，或选“全部载具本体与载具武器”。
4. 手动输入来源 ID 时每行一个，点击加入列表，再保存。
5. 勾选启用并保存。初始状态为关闭，没有默认禁止任何武器。

目前只接收 killed 事件，不支持普通未致死伤害检测，也不能阻止购买或装备。限制涵盖所有可识别来源类型，包括枪支、手雷、爆炸物、近战、载具、车载武器、建筑固定设施；未知名字可按完整 ID 精确限制。无可靠来源或无可靠攻击者 SteamID 的事件不处罚。

当前对局中首次使用受限来源造成击杀，发送私信警告；警告成功至少8秒后，再用任意受限来源造成击杀即踢出。跨受限武器累计。多人同时死于同一爆炸不会在警告前升级处罚。自杀不计入；队杀在来源受限时计入。

重复 Feed 事件不重复处理。重新加入仍违规可再次踢出，成功踢出后至少间隔60秒。换图或保存新规则重新开始计数。断线、过期事件、换图、数据不足、超大积压不触发处罚；发送警告失败不算已经警告。请求结果未知不会自动重试该事件，不会当作成功。

设置需要自动化管理、玩家管理、私信权限。执行记录在同页显示，也进入审计日志。禁用后停止新的操作；已发出的游戏请求无法撤回。
