# 自动强弱阵营平衡

入口：服务器 → 自动化 → **强弱阵营平衡**。安装和升级后默认关闭，点击「开启候选监测（不自动调队）」才开始自动选人。

**当前自动交换被阻止**：2026-09-26 实测用户游戏服 `++Wardogs+Live-CL-501228`，`GET /v1/players` 只有 `name, steamId, faction, kills, deaths, cash, pingMs`。没有当前死亡、重生、装备状态；能力列表也没有仅在死亡时生效的条件调队接口。按要求，活着带装备时不能调队，因此此版本只保存待交换名单，绝不调用调队或强制死亡接口。

## 什么时候进入候选计划

1. 当前是有明确阵营积分的三队对局。
2. 最高分队必须比**另外两队各高出超过40分**。例如100／60／20不触发，101／60／20可以触发。可以在设置中调高到60分或更高。
3. 默认开局及面板重新建立观察后的300秒内不调队；参数允许180～1800秒。地图结束、切换、当前状态过期时不调队。
4. 领先和落后阵营必须唯一；两个落后队并列最低分时等待分出先后。
5. 两边各有至少3名连续在线满180秒、近期没有Warcon调队记录的可用玩家，并且三对交换都能改善弱队的KPM／KD排名。
6. 当前对局有覆盖180秒的Feed记录，最近事件没有超过60秒，并且事件时钟与当前对局相符。

## 选哪六个人

- 领先队取KPM最高的3人；KPM相同，KD较高的优先。
- 最低分队取KPM最低的3人；KPM相同，KD较低的优先。
- 两项均相同时用SteamID稳定排序，不随机反复换人。
- KPM = 最近180秒已接收的有效击杀数÷3。包括枪械、载具等，排除自杀和已知队杀；不要求属于纯步兵击杀。
- KD = 本局已接收的有效击杀数÷max(本局死亡数,1)。这是本局Feed数据，不是生涯KD；缺少当前对局数据时不运行。

一份计划是3对、共6名玩家。中间阵营不动。每局只维护一份计划；分数和候选变化时重新计算，换图、数据失效或关闭功能时旧计划作废。

## 死亡／重生限制

必须确认玩家已经死亡，或刚重生且尚无装备，并确保游戏端执行时仍满足这一条件。Kill Feed 的死亡事件存在网络和处理延迟，不能当成当前生命状态；死亡数增加同样不能证明玩家还未重生。

原有 Warcon 调队动作会修改阵营再调用 `/kill` 强制重新出生，本功能不使用该动作。当前仅提供候选监测开关和阻塞说明；要真正自动交换，需要游戏端插件或官方接口提供可信状态及执行时条件检查。拿到该能力后，还需处理满员和两名玩家不能同时安全交换的情况。
