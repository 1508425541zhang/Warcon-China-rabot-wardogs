# AI 辅助审核

入口：服务器 → 社区风控 → AI 辅助审核。

1. 组织管理员填写服务商的 HTTPS API 基础地址（包含服务商要求的 /v1 或兼容路径）。
2. 填写 API 密钥，保存。支持 OpenAI 兼容 Chat Completions，并不限定模型厂商。
3. 点击读取模型列表，再选择模型并保存；不支持 GET /models 的厂商可手动输入模型 ID。
4. 测试已保存的模型。测试不发送玩家数据，可能产生少量调用费用；组织请求间隔65秒。
5. 选择案件并预览 JSON，点击发送至已配置模型并预判。

密钥使用应用 ENCRYPTION_KEY 加密存入 PostgreSQL，不回显；留空保留旧密钥，更换地址必须重新填写。删除配置立即阻止后续调用，已发出的请求可能仍完成。

发送内容：所选案件的全部已保存源事件、冻结规则/统计结果、处置及审核记录、最近20条案件索引（注明截断）。不是服务器全量日志；旧案件没有保存的事件无法恢复。没有图片、数据库连接凭据、RCON 密码或 API 密钥。历史列表与玩家名字属于当前查询信息，案件快照为当时信息。

没有后台轮询模型，没有聊天历史。相同案件资料和模型参数复用持久化结果；结果变化才重新请求。输出默认1200 token，可调256–4096；支持 max_tokens / max_completion_tokens。输入超过256 KB拒绝发送，不静默裁剪；供应商上下文不足也会报错，不生成成功结论。

模型结果只供参考，不修改案件的人工审核状态、风险分或自动处罚。输出结构不合格或被截断时不会保存成有效结论。管理员仍需在原案件页面保存人工结论。所有有风控查看权限的管理员可请求预判，配置及连接测试仅限组织管理员。

公网 HTTPS、DNS 地址校验和连接地址固定、禁止重定向、60秒超时、响应1 MB上限。当前不支持内网 Ollama 地址、图片、工具调用或供应商专用非兼容协议。
