# 案件审核与七天封禁

进入服务器的「社区风控」，展开案件证据，由组织所有者填写至少 5 字的审核理由。

- **确认违规／作弊**：点击「确认违规并封禁7天」，保存审核结论，同时向本服务器封禁名单写入七天封禁，并排队踢出在线玩家。
- **证据不足、误判、数据错误**：只保存审核结论，不新增处罚。

封禁与审核结论在同一个数据库事务中提交。任一写入失败，全部回滚。该操作属于管理员明确作出的处罚，不受自动风控的样本量、人数或自动处罚开关限制；AI 审查仍只给建议，不能调用人工审核处罚。

## 查看结果

案件证据内会显示人工处罚、实际到期时间以及即时踢出的状态。封禁名单保存成功和游戏服收到踢出指令是两件事：玩家离线、游戏服失联时，踢出可能跳过或失败，但名单上的封禁仍然保留，Worker 在玩家重新出现时按封禁名单执行。面板和 Worker 必须持续运行。

已有更长期或永久封禁不会缩短。重复保存同一个案件、修改理由、并发点击，都不会再次创建处罚或延长七天期限。七天从首次保存确认违规的时间开始计算。历史上已审核的案件不会批量补罚；管理员再次明确保存确认违规时才会执行。

## 更正与撤销

修改审核结论不会自动解封。需要解除处罚时，去封禁管理移除对应封禁；已经排队、尚未执行的人工踢出会在发送前检查封禁是否仍有效。同一案件的处罚撤销后，再次保存不会恢复该处罚。如需重新处罚或改成永久封禁，请在封禁管理中另行操作。

实现记录：`integrity_actions.source=REVIEW`，案件 ID、名单记录、审核人和踢出队列互相关联；每个案件使用唯一的人工处罚 ID，确保幂等。
