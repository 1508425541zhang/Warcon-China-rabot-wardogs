# 硬性数值限制

入口：服务器 → 自动化 → 硬性数值限制。默认关闭；这是社区自定规则，不是作弊结论，不会封禁。

1. 勾选需要限制的项目：KPM、KD、每分钟金钱净增长。
2. 在输入框填正数上限。严格超过才违规，等于上限不违规。未勾选项目不参与。
3. 填统计窗口（60～900秒，默认180秒）和KD最低击杀数（1～1000，默认10）。
4. 点击“保存并启用”。至少等待一个完整新窗口，重连、换图或计数重置后重新积累。
5. 首次超限私聊警告；警告送达后，再取一个完整、不重叠的新窗口判定，仍超限才踢出。KD单独超限还须有新增击杀。每人每局每版规则最多踢出一次。
6. 下方查阅最近50条记录，包括实际数值、阈值、时间区间和结果。接口超时/结果未知不会被当作警告送达，也不会自动重复发送。

## 计算口径

- **KPM**：玩家列表在窗口中的击杀计数增量÷实际分钟数，包含游戏计分板计入的所有击杀，不是纯步兵KPM；不依赖Kill Feed。
- **KD**：当前对局击杀÷max(死亡,1)，达到最低击杀数才评估。
- **金钱效率**：窗口末余额减去起始余额，再除实际分钟数。消费会降低它；这不是无法观测的总收入。
- 每30秒持久化计数。采样缺失、计数减少、离线重连、采样间隔超过65秒、观察状态不可信时不使用该窗口。
- 保存配置会重新积累窗口和警告。关闭立即阻止后续尚未发出的处置。已发往游戏服的请求无法撤回。

此功能与现有风险分、委员会和武器限制独立，原有级别设置保持不变。不建议用测试阈值在真实服务器随意启用。
