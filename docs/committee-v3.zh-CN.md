# 五专家委员会（v3）

本版模型：ensemble-server-round-v3。旧案件保留旧结论，新规则不追溯执行旧候选。

## 五张票

1. 击杀节奏：KPM、受害者数、爆发与间隔，P90可疑，P95高度异常。
2. 精准度：当前服务器过去30天群体爆头／穿透分布，同武器单独比较，P90可疑、P95高度异常。不是个人对个人；其他服务器和外部导入记录不混入此服务器的精准度分布。参考玩家等权重。
3. 生涯偏差：沿用100个历史窗口、10个活跃日、稳健偏差4／8及持续偏高条件。
4. 变化点：本局所有武器、载具等有效击杀，以完整15秒区间计算击杀速率；至少20个区间（5分钟）。只使用本次连续在线期间的数据，排除自杀、已知队杀及重复事件；最近3段持续上升并达到CUSUM 8／15给出可疑／高度异常。
5. 持续异常：本局和过去24小时多局的独立异常，2次可疑、3次高度异常。重叠证据及同一事件不重复算次数，持续异常自身不循环制造新异常。

## 投票与真实踢出

- 每位专家各一票，未知不当成正常或可疑票。
- 至少2票可疑或更高：观察。
- 至少3票高度异常，或至少4票可疑及以上：生成待审核案件，**不直接踢出**。
- 唯一委员会自动踢出通道：**180秒步兵KPM严格大于4，而且除击杀节奏外，至少另一位专家可疑或高度异常**。无需连续两个／三个60秒均达标，无需等待人工审核。
- KPM严格大于2增加6分；等于2不加此项，等于4不满足直接踢出条件。旧模式的评分表保留；此项用于统计模式与Shadow记录。
- 自动处置保留在线人数、数据健康、有效版本、参考样本、频率和组织开关保护。本通道仅踢出；案件证据与处置记录保留，自动处置无需挂起等待人工审核。

更新后需要重建新版本基线；重建完成前不拿旧版本分布进行自动处罚。
